# 架构与数据边界

BIT101-iOS 由 App 宿主、本地 SwiftPM 模块、Widget、Live Activity 与 Watch 组成。App 负责组装依赖和平台资源，各功能模块维护所属业务状态。模块定义以 [Package.swift](../Package.swift)为准，验证入口见 [构建与测试](TESTING.md)。

## 模块职责

| 模块或目录 | 职责 |
| --- | --- |
| `BIT101-iOS/` | 启动、登录、账号生命周期、设置、路由与平台适配 |

| `ScheduleContracts`、`ScheduleSharedStore` | 扩展共用快照、日程发生时间、持久化与版本边界 |

| `ScoreDomain`、`ScorePorts` | 成绩模型、比较、筛选及查询与缓存端口 |

## App 组装与状态流

App 在壳层组装账号存储、网络客户端、学校服务、媒体环境、平台动作和页面依赖。功能入口消费同一组装环境；页面持有所属 ViewModel，跨页面跳转通过壳层路由和功能端口传递业务身份。

`AppStorageSession` 为账号生成偏好键和安全目录名，访客使用固定分区。任务创建时捕获账号、登录代际和页面请求代际；异步结果在提交页面或持久化前核对所属身份。账号切换由生命周期协调器重载缓存、偏好、同步状态和扩展展示。

请求、保存、上传和清理由对应场景持有。页面或账号生命周期结束后取消所属工作，迟到结果继续接受归属核对。更新、提醒、同步和网络警告按各自生命周期协调，用户操作触发的学校请求由所属动作继续执行。

学校密码输入、学校短信、教学中心认证与预热、社区认证恢复共用按账号代际合并任务的协调器。等待者取消时立即结束自己的请求，其余等待者继续共享输入；全部等待者离场或账号变化后取消所属认证操作。

SwiftPM 使用 Swift 6.2 与 MainActor 默认隔离。页面状态由 MainActor 发布；跨隔离域值声明 Sendable，纯业务类型按职责采用 nonisolated。JSON 解码、成绩解析和较大响应转换使用 `@concurrent`，继承调用任务的优先级、取消与任务局部值。同步磁盘工作通过 `StorageFileExecutor` 的独立串行队列执行，文件仓库在所属 actor 中维护顺序。

## 日程与成绩

`ScheduleRepository` 为课表、DDL 和空教室提供账号内共享数据，各子功能拥有请求与提示状态。仓库串行提交保存，排队期间继续保留页面编辑；外部同步更新通过基线进行三方合并。相同记录的并发分歧进入明确的版本选择，选择作用于冲突记录，双方独立编辑共同保留；合并完成后继续保存并同步。

空教室按学校时区的自然日控制自动刷新：每日首次进入更新校区、当前教学楼目录与占用，同日复入和重启复用账号内缓存。教学楼目录按校区记录每日刷新，手动刷新同时更新当前目录和占用。占用缓存按学期、教学楼和查询日区分，节次与当前分钟筛选在本地计算；切换教学楼首次查询后同日复用。自动查询失败后保留当天有效结果与成功更新时间，手动刷新支持立即重试；跨日占用沿过期提示引导刷新。本地日程存储受阻时，空教室选择与在线查询继续在所属账号内存中运行。

调课编辑使用全校区已缓存的楼宇目录，保留原地点并支持自定地点。分享码投影已排课程，待排条目保留在本地。自己的课表小组件定位主课表当前周；系统日历事件优先使用本地目标学期快照，支持离线定位。

学校课程与首周日期形成课表更新，考试接口独立返回状态；考试暂时故障时保留同学期已有考试，成功返回的空列表清空该学期考试。学校课程、考试和首周日期按学期存入 `schedulesByTerm`，展示由当前学期、手动首周日期和调课规则派生。完整日程按相邻学期滚动保留，归档课程供成绩匹配。个人日程、分享课表、手动课程规则和手动 DDL 使用稳定身份；分享导入保存独立记录和来源时间表。

磁盘与云端准入共用身份、日期、节次、课程和事件约束。支持格式的有效内容按字段和记录恢复，加载结果携带恢复状态；日程页与设置页共用读取重试和恢复确认，页面继续展示有效内容，原文件保留至用户确认。确认后提交完整快照并恢复编辑与云同步。同步选择独立恢复，未知选择保持关闭。

日程根文件损坏时，用户可确认以当前有效内存重建所属账号的缓存，确认动作核对账号代际。写入前再次核对磁盘，期间出现的可读版本继续保留。文件访问受阻、超出预算或较新格式版本沿原文件保护与重读流程处理。

课程中心与乐学独立推进 DDL 同步，各来源成功后立即保存并展示。课程中心记录作业所属课程，成功课程替换其快照，失败课程与归属待确认的缓存继续保留；完整成功后完成来源删除判定。课程目录或共享活动身份发生分歧时保留该来源快照。学校事件完成状态及显式撤销按稳定 ID 保存并同步，手动事件独立维护。课程中心分页、并发、响应期限与 ICS 支持范围由服务实现及对应契约测试维护。

成绩查询将在线获取与本机持久化分开处理。缓存读取受阻时继续请求学校服务，在线结果留在页面内存，保存问题单独呈现。简略结果沿匹配课程保留已确认的详细字段，取消详细查询后恢复原有完整快照；详细请求失败时保留可用结果及对应缓存。页面复入与外部缓存变更同样保留当前可用内容。

成绩筛选从实际成绩字段生成选项，学校课表补充未出分课程和学期上下文。成绩缓存区分简略与详细更新时间，读改写保留支持格式中的扩展字段。简略阶段保留匹配课程的已知详情，全选筛选随返回字段目录更新。成绩缓存与筛选存储提供账号内的确认恢复，重建时保留当前可用成绩。恢复与在线刷新互斥，恢复结果核对账号和展示代际，页面使用所属操作的有效数据。可信成绩单将短信认证与下载分开，重试复用已认证挑战。各页完成校验与后台解码后立即展示，补页继续独立推进；来源失效时保留已取得的有效页。重试向同一报告补齐缺页，重新申请会取得新的报告来源，旧报告与新分页共用存活位图预算，预算需要时切换到已校验的新报告分页。短信续接由页面模型持有，页面退出时取消下载。图片保留原始页码，由页面内存持有并按页数、传输、位图和整体等待预算验收。报告级认证或来源失效会及时结束余页下载，重试重新申请报告；网络诊断结合失败信息与完整页码集合判断可用性。

## 社区、消息与草稿

各社区场景分别维护首屏、分页、搜索和刷新代际。源页推进与去重状态分开记录，重叠页在当前任务内继续请求，最终统一发布游标；持续停滞进入可重试状态。刷新期间保留已有内容与游标，成功响应提交新的首屏状态。

课程、话廊与文章的详情、评论和编辑由所属功能服务承接。详情与评论请求各自完成时更新所属状态。话题详情复入保留已加载评论及交互确认，内容筛选变化在现有状态上更新可见内容；评论区域提供独立重试，联网与回到前台处理失败读取。课程搜索在加载和失败期间保留输入区域，列表、详情和历史成绩在联网及回到前台时恢复失败读取。课程和文章复用公共加载状态。文章列表与搜索共用集合的刷新、分页、取消恢复和预览生命周期，各页面持有独立集合与查询条件。跨页面共享的评论呈现和正文链接归 CommunityUI，领域分页与草稿合同归 CommunityCore。长帖与长评论提供原生全文阅读，正文预览和链接扫描继续受展示预算约束。文章富文本逐块准备并响应取消，结构异常的块保留完整原文入口及相邻有效正文。文章内容解析、上传、创建及编辑均核对页面和账号生命周期。文章与帖子编辑通过取消入口确认待保存的修改。评论发送结果待确认时保留完整提交范围，用户核对列表并确认后可再次发送对应评论。

文章列表刷新期间保留当前作者信息，首屏成功后统一交接预览代际并加载新作者；刷新期间的旧行继续使用已有内容。文章预取按账号、代际和登录状态保留详情，凭据续期后继续复用同账号内容。详情打开时先展示预取内容，再重新确认服务器正文和交互状态；读取失败时保留可用内容。可选鉴权的公开读取在凭据恢复受阻后尝试公开访问，读取全过程继续核对账号代际。响应保留查看者认证来源，公开内容沿其来源保存缓存，点赞操作等待认证后的读取结果。课程共享资料入口独立于历史成绩状态，已有历史图在刷新和错误期间继续展示。帖子及文章详情的下拉刷新共同触发媒体重试代际。

消息中心先读取历史首屏，再处理未读窗口保存与服务端确认。摘要端点或本地已读文件受阻时，消息正文继续可读，角标与确认状态分别保留恢复信息。历史分页使用实际末条 ID；服务端分类清零通过独立确认请求执行，保存与恢复游标共同保护请求期间新到达的消息。

已读快照位于账号目录的 `message-read-snapshot.json`，通过受保护的原子写入提交。已读历史按分类保留 1024 项，显式未读候选与确认恢复游标独立保存。实例变更按账号发布，外部写入和账号切换使查询缓存失效。

发帖、文章和建议复用账号草稿存储与串行写入事务，元数据由各自快照组装。文章通过暂存和恢复保留输入，所属文章及新建内容汇集于固定的 `composer-paper.json`；编辑版本随草稿保留，发布清理核对所属账号与记录版本。文章条目独立读取和保存，损坏条目保留在原归档中，有效草稿继续使用。用户确认恢复存储后保留有效条目并清理损坏内容，当前页面输入继续保留。恢复动作捕获所属账号，并在执行前核对当前账号。文件访问问题与较新格式版本继续保护原文。

发帖与评论共用图片草稿、上传状态、重试和移除。图片读取及准备完成后进入本地草稿，上传按图片身份持有，取消后保留字节并提供重试；发帖保存等待本地导入完成，失败图片继续保留原始选择。上传成功的资源标识随元数据保存，恢复草稿继续复用已有上传结果。图片草稿的元数据与资产分开保存，单张图片预算为 1 MiB，最多九张。读取结果区分缺值、完整恢复、图片局部恢复、元数据读取问题和格式版本差异。单张图片缺失或超限时先恢复文字与其他图片，并提示重新选择；原始内容保持至后续保存或明确放弃。

文字暂存比较现有图片名称与实际字节，复用相同资产版本；图片内容或顺序变化后提交新资产与元数据，再清理旧版本。支持的历史快照在有效保存完成后迁入所属账号路径。提交清理捕获原账号和元数据版本，后续编辑的新草稿继续保留。

日程、DDL、课程和举报编辑器按当前输入保护下滑关闭，取消操作确认放弃。举报提交期间保护已捕获的输入，原弹层等待回执。

发帖、文章或建议取得成功回执后，页面完成退出和列表更新，所属任务继续执行草稿清理。帖子更新与删除通过目的地回调通知来源列表，帖子编辑和草稿恢复保留已选声明。清理问题保留原草稿及诊断。发帖结果待确认时保留编辑内容，引导用户关闭编辑页并核对发布列表；建议响应丢失时保留完整载荷，重试复用已捕获的提交身份。

## 网络边界

`HTTPTransport` 与 `HTTPClient` 提供统一传输、观察和错误映射。URLSession 由所属传输实例持有，连接池在 App 选择 Cookie、缓存、重定向、连接等待及期限策略。最后一个客户端释放传输后结束在途请求并关闭会话，Cookie 容器切换沿同一资源生命周期处理。

| 会话 | 边界 |
| --- | --- |
| 社区 | 共享所属账号的 Cookie、缓存与连接池 |
| 普通成绩与可信成绩单认证 | 共用认证传输，各自持有业务 challenge |
| 敏感下载 | ephemeral 配置，正文由当前页面持有 |
| 学校 CAS | 按业务选择手动重定向与 HTTPS 升级策略 |
| 教学中心及课程中心 | 独立会话、可失效认证状态和短信续接 |

社区认证失败由统一恢复策略协调续期与重放。凭据遭拒时暂停社区鉴权请求，保留本机账号、学校凭据与缓存阅读；账号设置使用 BIT101 密码重新认证，主动退出负责清理会话。连接问题保留当前会话。请求发送、恢复、解码与副作用提交继续核对登录代际。学校会话恢复、短信及有副作用的请求分别按所属协议处理重试。

社区删除接受目标端点返回的成功状态或 404，并继续校验最终请求方法与账号代际，支持响应丢失后的幂等重试。网络恢复观察进入已连接状态；消息页持有交互任务，分类切换与页面退出取消所属恢复，保留待续接的已读窗口。空教室刷新与选择查询共享任务所有权，选择变化取消旧查询，请求参数在认证前捕获。

连接池限制整体资源期限并保留更短的业务期限；持续响应受同一预算约束。响应聚合沿同一 URLSession 任务的系统数据块追加并检查取消，JSON 和媒体各有字节上限。错误正文按解析与展示预算处理，结构化错误和简短纯文本承接提示，HTML 与未知结构沿 HTTP 状态呈现。

`NetworkPathState` 提供实例级可观察连接快照，页面在连接恢复时处理所属场景的重试。网络提示沿既有队列异步呈现并保留冷却窗口，请求持续执行。诊断在固定容量中兼顾近期请求、故障与相邻上下文，并按账号代际隔离；业务状态与响应解析失败回写对应请求记录，响应解码保留字段路径和底层原因，页面沿用简明错误文案。诊断同时保留初始与最终请求事实，学校服务恢复入口优先采用最终页面；两端地址共用报告脱敏与容量规则。

WebVPN 初始化失败按学校认证通道异常呈现，覆盖登录和社区会话自动恢复；学校认证限制、会话失效和资源访问限制沿具体响应给出原因与学校官方入口。客户端和报告受理端共用错误来源边界，这些异常在正式报告配额预留和写入前结束上报；客户端解析、本地缓存及协议适配问题继续保留开发者诊断。学校请求失败时继续保留已有课表和本地编辑能力，会话恢复沿所属账号有界推进。

外部 BIT101 后端、Android 和 Web 项目属于只读参考及对应维护者的工作范围。iOS 保存请求与响应证据，负责协议适配、错误呈现和恢复。Cloudflare 自有 Worker、隐私页面和分享链接由本仓库维护，部署与发布沿明确授权执行。

## 存储与账号隔离

| 数据 | 位置与生命周期 |
| --- | --- |
| 学校凭据与社区会话凭据 | Keychain，按账号选择与安装状态维护 |
| Cookie、challenge、access token、短信状态 | 所属会话内存与 Cookie 容器，按账号及失效事件更新 |
| 主题、旋转、自动更新检查等设备偏好 | 应用级 UserDefaults |
| 账号设置、成绩筛选与消息已读 | 账号级偏好或所属业务仓库 |
| 日程、成绩与草稿 | 账号隔离的 Application Support 文件 |
| 可重建图片与头像 | 系统 Caches，按容量和近期访问回收 |
| Widget 与 Watch 展示 | App Group 中的精简快照及版本边界 |

`AppFileService` 统一文件内容、目录、元数据、保护和规范路径操作。生产读取先验收容量，再读取有界字节；写入准备所属目录并使用受保护的原子提交。用户持久目录参与系统备份，历史备份元数据在场景启动后完成一次迁移，日常写入维护所属目录的策略；可重建缓存和临时展示沿各自生命周期清理。

`AccountScopedCodableStore` 统一偏好键、迁移、编码和扩展字段保留。读取区分缺值、有效值与损坏值；未知格式保留原数据并暂停对应保存与云同步。账号设置与成绩筛选提供独立恢复入口，确认后恢复当前账号快照并重建所属同步域的派生合并基线，日程、成绩、登录及设备偏好保持所属生命周期。

本地数据清理通过 App 组装的资源所有者执行，覆盖偏好、凭据、文件、Cookie、URLCache、媒体和共享快照。清理前等待已接收的存储操作结束，异常按资源保留诊断。社区线上写入的待恢复事务先完成对应恢复，再按账号范围处理本机清理。

## iCloud 同步

课表通过 CloudKit 同步用户状态，App 负责容器、记录和 system fields 适配；学校正文由本机学校同步持有。同步状态机维护拉取、合并、冲突选择和推送的互斥关系，并在启动、前台恢复和账号切换后沿所属生命周期运行。

本机持久化保存已确认的用户状态作为三方合并基线。独立记录按稳定 ID 合并，相对基线的删除继续传播，顺序和同一字段的并发分歧进入冲突决策。比较写入核对磁盘版本和云端基线，保存期间的新编辑继续保留待同步状态。

成绩 KVS 同步使用加密载荷，密钥由 iCloud 钥匙串协作。实验性偏好同步分别管理设置、筛选和已读业务域；字段修改、可选值清除和已读并集按所属版本合并。账号事件、保存通知和同步实例显式注入，业务存储成功后推进对应云版本。

## 媒体与设计系统

通用颜色、字体、间距、页面状态、刷新行、编辑器、标签、评论和原生交互组件归 DesignSystemKit。社区共享展示归 CommunityUI，功能页面消费公共组件并持有实际业务动作。详细界面约定见 [设计系统](DESIGN_SYSTEM.md)。

媒体环境注入传输、图片文件服务、预览文件服务和容量协调器。`CommunityImage` 统一验收 HTTP(S) 图片地址，媒体入口将 HTTP 升级为 HTTPS，缓存与在途请求沿安全地址合并。头像、列表静态图和详情优先读取已有原图及低清缓存；下载按低清与原图地址恢复，低清故障时继续尝试原图。列表和详情静态图共用加载器，详情在低清展示后继续准备原图。照片读取在系统提供者的有效期内按预算完成，压缩和静态、动画解码在后台执行；图片、头像和预览共用原始字节及位图预算。草稿缩略图按预览数据与显示比例在后台准备，编辑界面重绘复用已准备的位图。动图原文件就绪前保留静态预览，原图加载失败后继续展示可用图片。图片缓存写入故障时，有效字节进入受容量约束的内存缓存并继续显示；旧文件清理沿后台存储执行器完成。Quick Look 使用明确准备的本地 URL，来源视图结束时关闭预览并释放资源。启用系统“减弱动态效果”时，渐进换图直接更新。

活跃预览文件由所有权登记保护，文件创建、登记、回收和清理共享同一资源边界。静态位图、头像与 GIF 各自维护显示缓存，内存压力释放可回收预算，等待中的视图在预算可用时继续加载。

磁盘图片配额共用于话廊和头像。首次或到期扫描建立容量与访问时间库存，写入按条目更新容量并执行回收，显式策略变更和清理更新库存。回收跳过活跃展示文件，按近期访问顺序释放可重建内容。文件工作在独立执行器进行，主线程维护界面会话。

## Widget、Watch 与 Live Activity

App 将当前账号日程转换为精简共享快照，包含课程、个人日程与 DDL 的扩展展示字段。DDL 摘要提供空标题显示值，按共享字段的 UTF-8 预算截取文字，身份或日期异常的记录独立过滤。共享身份、修订与时间线规则归 ScheduleContracts，磁盘协调归 ScheduleSharedStore。Widget、Watch App 和 Watch Widget 分别消费相同的业务合同。

个人日程按重复日期展开，与课程按开始时间合并；个人日程独立于学期首日。DDL 时间线复用一次排序，围绕当前可见条目生成刷新节点，窗口推进后继续请求下一批。

共享快照读写在后台执行，账号切换和退出清空所属展示。凭据读取待恢复时保留已发布课表、提醒与活动，读取恢复后按账号代际继续同步；装机就绪随登录呈现和凭据恢复重新核对。Watch 清理保存精简版本边界，重启后继续拒绝迟到旧传输，新版本到达后恢复。请求、回复和持久化共同核对最高已接受修订，断线后支持前台再次请求。

日历导入、提醒和 Live Activity 由 App 平台适配器消费课程及账号上下文。日历事务串行维护展开、写入与回滚，通知替换保留失败恢复边界；权限返回后再次核对账号。ActivityKit 属性独立于纯领域合同，系统界面与投递沿真机专项验收。

系统日历事件保存所属账号、学期及日程标记，链接回到对应课表详情。导入索引受损时，课表设置提供确认后的重建入口，从系统日历中近十年与未来十年的当前账号标记恢复批次，保留事件内容。批次按学期和日历归属维护，增量导入保留各日历中的其余事件；删除沿已记录日历的标记重新定位同步后改变标识的事件。

## 服务边界门禁

静态审计复用当前工具链的 SwiftSyntax 事实，核对依赖方向、资源归属、公开能力、自动学校请求、设计系统和测试登记。基础传输、媒体与平台资源按明确签名归属，新增业务能力进入对应网络和交互库存。

原生构建验收 Swift 类型、隔离与平台编译语义，行为测试验收状态、取消、失败恢复和持久化，UI 与人工专项验收真实控件及系统能力。检查器作者提供触发、合规和故障样例，较大源码按生命周期和职责审查，维护文件统一遵守 1000 行上限。

验证输入使用提交、环境和实际内容身份关联结果。编译缓存、工具链选择、测试库存、原始结果及发布证据由既有脚本维护；开发时选择受影响分组，检查器自测由统一审计集中执行。工作流命令、固定产物和 CI 范围统一见 [构建与测试](TESTING.md)。
